# KOReader home-screen tile

Original artwork (CC0): a sun rising behind an open book. 600x800, 8-bit grayscale.

The stock home screen takes the tile image from the `# Icon:` line of the scriptlet
(`kindle-files/documents/KOReader.sh`). Copy the PNG to `/mnt/us/koreader/resources/` and point the
`# Icon:` line at it. The catalog picks the change up once the stock UI rescans the file.
